# GESSA — نسخة الموقع المرتبطة بـ Supabase

## محتويات المشروع
- `index.html`: صفحة الدخول والتسجيل، مع الحفاظ على الواجهة الخارجية الأصلية التي أرسلتها.
- `home.html`: الصفحة الرئيسية ونشر المشاركات.
- `shop.html`: عرض المنتجات.
- `merchant.html`: طلب الانضمام كتاجر وإنشاء متجر وإضافة منتجات بعد الموافقة.
- `world.html`: صفحة العالم الافتراضي والمحفظة الأساسية.
- `onboarding.html`: تأكيد الهاتف برسالة SMS ثم إدخال تاريخ الميلاد.
- `reset-password.html`: إكمال تغيير كلمة المرور من رابط البريد.
- `admin.html`: لوحة المالك المنفصلة.
- `config.js`: ضع فيه Project URL والمفتاح العام فقط.
- `database/03_safe_upgrade.sql`: ترقية آمنة وإصلاح صلاحيات RLS وإنشاء الجداول الناقصة عند الحاجة.
- `database/OWNER_SETUP_TEMPLATE.sql`: منح حسابك صلاحية المالك بعد التسجيل.

## مهم قبل التشغيل
1. افتح `config.js` بمحرر نصوص.
2. استبدل `PASTE_PROJECT_URL_HERE` بعنوان مشروع Supabase.
3. استبدل `PASTE_ANON_PUBLIC_KEY_HERE` بمفتاح Publishable أو anon public.
4. لا تضع `service_role` أو أي Secret key في ملفات الموقع، ولا ترسله في المحادثة.

## قاعدة البيانات — حتى لا تتكرر الجداول
- إذا كنت قد شغّلت `01_schema.sql` و`02_schema_world.sql` سابقًا بنجاح، **لا تشغّلهما مرة أخرى**. شغّل فقط `03_safe_upgrade.sql` مرة واحدة.
- إذا لم تنشئ قاعدة البيانات من قبل: شغّل `01_schema.sql` مرة واحدة، ثم `02_schema_world.sql` مرة واحدة، ثم `03_safe_upgrade.sql`.
- ملف الترقية لا يحذف جداول أو حسابات أو منشورات أو متاجر أو أرصدة موجودة. وهو يعيد ضبط سياسات الأمان المطلوبة.

## تفعيل المالك
1. أنشئ حسابك من صفحة GESSA وأكد البريد الإلكتروني.
2. افتح Supabase > SQL Editor.
3. افتح `database/OWNER_SETUP_TEMPLATE.sql`.
4. استبدل `PUT_YOUR_OWNER_EMAIL_HERE` ببريد حسابك أنت، ثم شغّل الملف.
5. سجّل الخروج من GESSA ثم ادخل مرة أخرى. سيظهر رابط «الإدارة» لحساب المالك فقط.

## إعداد تأكيد الهاتف
- من Supabase > Authentication > Providers، فعّل Phone.
- أضف مزود SMS وإعداداته في Supabase. قد يفرض مزود الرسائل رصيدًا أو تكلفة.
- أضف رابط الموقع المنشور إلى Authentication > URL Configuration (Site URL وRedirect URLs).

## النشر
يمكن نشر مجلد المشروع كاملًا على Netlify أو استضافة Static Hosting. لا ترفع ملفًا واحدًا فقط؛ ارفع المجلد مع `assets` و`database`.

## ما هو جاهز وما يحتاج خدمة خارجية
- التسجيل بالبريد وكلمة المرور، تسجيل الدخول، استعادة كلمة المرور، إنشاء profile باسم المستخدم، المنشورات، المنتجات، وطلبات التجار: مهيأة للربط بقاعدة البيانات.
- تأكيد الهاتف يحتاج إعداد SMS في Supabase.
- الدفع الإلكتروني يحتاج بوابة دفع وحساب تاجر.
- العالم ثلاثي الأبعاد متعدد اللاعبين يحتاج بناء عميل ألعاب وخادم لحظي مستقل؛ الصفحة الحالية هي أساس الربط وليست لعبة مكتملة.
